# Nomisma Labs handbook

The handbook records the purpose, architecture, development conventions, and plans for
Nomisma: a software workshop for building trading systems from reusable components.

Start here:

- [Statement of intent](memorandum.md): purpose, development approach, and key decisions.
- [Layers and integration boundaries](master-plan/layers.md): responsibilities and dependencies.
- Layer plans: [toolchain](master-plan/toolchain-layer.md), [core](master-plan/core-layer.md),
  [services](master-plan/service-layer.md), and [applications](master-plan/application-layer.md).
- [Licensing and ownership](master-plan/licensing.md): the component licensing policy.
- [Packaging and distribution](master-plan/wip/packaging.md): planned delivery formats and workflows.

Detailed APIs, dependency pins, release histories, and validation results live in the
component repositories linked from these documents.
